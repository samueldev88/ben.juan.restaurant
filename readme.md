# Ben Juan Restaurant 🍽️

Site **fictício** de restaurante, desenvolvido como projeto de portfólio para praticar front-end (HTML, CSS e Bootstrap), sem uso de frameworks JS ou back-end.

> ⚠️ **Este é um projeto demonstrativo.** Não é um restaurante real — os contatos (Instagram e WhatsApp) exibem um aviso informando isso ao serem clicados.

## 🔗 Demo

👉 [Ver site no GitHub Pages](https://samueldev88.github.io/ben-juan-restaurant/)

## ✨ Funcionalidades

- Cardápio completo com categorias (entradas, pratos principais, sobremesas, bebidas)
- Layout escuro com identidade visual própria (paleta dourada/âmbar)
- Página de **reserva de mesa** com formulário passo a passo e confirmação animada
- App de **pedidos** (cardápio do cliente + painel da equipe) com carrinho, acompanhamento de status e pagamento simulado
- Totalmente responsivo (mobile e desktop)
- Seção de contato com aviso de site fictício ao clicar em Instagram/WhatsApp

## 🗂️ Estrutura

```
ben-juan-restaurant/
├── index.html      # página inicial (cardápio, sobre, contato)
├── reserva.html     # reserva de mesa
├── pedidos.html      # app de pedidos (cliente + equipe)
└── style.css        # estilos compartilhados (paleta de cores e navbar)
```

## 🛠️ Tecnologias

- HTML5 + CSS3
- Bootstrap 5.3 (grid, ícones e componentes)
- JavaScript puro (vanilla)
- Google Fonts (Caveat, DM Sans, Poppins)

## 📌 Observações

Todos os dados (cardápio, pedidos, reservas) são simulados no front-end — não há banco de dados, autenticação real ou processamento de pagamento.
